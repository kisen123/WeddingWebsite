# Wedding website design rules

- Match the provided reference image, if one is given, closely.
- Keep all content within the inner safe region of the wavy border.
- Use responsive CSS Grid and fluid typography.
- Do not solve responsiveness by uniformly shrinking the page.
- Render the border as inline SVG.
- Prefer parameterised SVG generation over arbitrary path-coordinate edits.
- Test at 390x844, 768x1024, and 1440x1000.
- Run Playwright screenshot tests after visual changes.
- Do not accept horizontal scrolling.
- Preserve accessible semantic HTML.
